- 正式程序只使用 Rust/Tauri，旧 Go 版本只保留为归档参考。

- AI 助手只在明确 `@DH`、`@ DH` 或旺商聊真实提及元数据时回复。
- 确定性机器规则不依赖 AI；AI 控制规则与 AI 助手相互独立。
- 新安装默认不启用群、规则、知识库、计划、预测或自动群名片。

## 4. 关键历史结论

- 11:15:21 的旧频率测试消息没有命中规则，因此它没有执行撤回，也不属于撤回成功证据。
- 后续唯一标记的验证码测试消息已经完成真实 NIM 撤回和历史回读验证。
- 生产能力不再只根据旺商聊脚本 SHA 统一锁定；ZCG 基线路由通过运行时只读探测决定可用性。
- 群公告使用旺商聊 Electron/NIM 专有链路，需要写入后回读公告历史确认。
- 成员资料变更回调在当前旺商聊版本不稳定，生产逻辑保留 60 秒完整名单对账。
- 写操作使用账号级顺序队列，调用间隔至少 500ms；这属于协议保护，不是规则冷却。
- AI 上游偶尔返回解释文字而非语义分类 JSON；此时记录失败、零动作并继续处理后续消息。

## 6. Windows 测试顺序

### A. 生产包边界

- 解压 portable ZIP。
- 确认没有 `DH-Fixture.exe`、Fixture 字样入口、`9233`、`51300`、测试数据库、PDB、Source Map、源码或开发命令。
- 核对 EXE 和 ZIP SHA-256。
- 用 `tauri3/scripts/test-windows-real-machine.ps1` 执行自动探针。

### B. 窗口、任务栏和托盘

- 任务栏与托盘均显示白色圆角底 DH 图标。
- 最小化按钮只缩到任务栏。
- 点击当前活动任务栏图标遵循普通 Windows 最小化行为。
- 只有点击右上角 X 才弹出“挂到托盘 / 退出 DH BOT”。
- 托盘可显示、暂停/恢复自动化、退出。
- 退出后 5 秒内没有 `DH-BOT.exe` 及其 WebView2 子进程残留。
- Explorer 重启后托盘图标恢复。
- 验证 100%、125%、150% DPI 和窄窗口布局。

### C. 旺商聊启动与 9222

- 旺商聊未运行：DH BOT 自动启动带 `--remote-debugging-port=9222` 的旺商聊并置前。
- 旺商聊已运行但没有 9222：先询问，再精确重启，不处理其他程序。
- `curl.exe --noproxy "*"` 读取 `/json/version`、`/json/list`，必要时验证 `/json` 回退。
- 系统代理开/关各跑一次，回环请求都不应走代理。
- 旺商聊退出后，DH BOT 应恢复等待或重新启动，不停留在旧错误。
- DH BOT 退出时不结束旺商聊。

### D. 登录状态复用

- 通过 DH BOT 启动的旺商聊完成一次密码登录并等待 NIM 就绪。
- 退出 DH BOT，再退出旺商聊。
- 重新打开 DH BOT，确认复用 `dh-primary` 并进入原账号。
- 重启 Windows 后重复验证。
- 旺商聊升级后检查登录分区维护状态；恢复脚本时不删除 Cookie、Token 或 Local Storage。

### E. Windows 真实群最终冒烟

按以下顺序，每一步保存消息 ID、动作 ID、协议回执和回读结果：

1. 只读同步群列表、成员名单、角色与能力。
2. 发送唯一标记普通测试消息。
3. 从普通成员账号发送唯一标记的“请提供验证码”消息。
4. 确认机器规则命中且只产生一个撤回动作。
5. 确认路由为 `nim.recallMsg`，历史回读不再包含该服务器消息 ID。
6. 短时禁言后立即解禁，并回读成员状态。
7. 临时修改名片后确认自动恢复；保存并恢复原名。
8. 新增测试公告、读取公告历史、编辑、置顶/取消置顶，再恢复原公告。
9. 计划任务用一分钟窗口验证全群禁言/解除，并在结束后恢复允许发言。
10. 移出成员只在 Fixture 中验证，不在真实群执行。

### F. AI 与知识库冒烟

- 使用 Windows 设置页录入测试 Provider，不在日志或报告写密钥。
- `/v1/models` 中确认模型存在，再执行最小 Responses 调用。
- 普通文本保持静默。
- `@DH` 与旺商聊真实提及当前账号都收到回复。
- 临时知识库绑定当前群，使用唯一事实提问；解绑后不再引用。
- 重复 FAQ 验证缓存命中。
- 审计包含 Provider、模型、知识片段数量、缓存状态、模型耗时和总耗时，但不含完整提示词与密钥。

### G. 预测

- 当前生产预测保持停用。
- 没有 `DH_PREDICTION_TOKEN` 或其他已验证可持续凭据时，健康状态必须明确显示数据源不可用。
- 不生成候选方向，不用本机时间伪装开奖时间。
- Fixture 可继续验证正常、缺期、乱序、重复、过期和模板回退。

## 7. 长时间稳定性

- 建议运行 8 至 24 小时。
- 覆盖旺商聊页面重载、NIM 503、断线重连、旺商聊重启、Windows 睡眠/唤醒。
- 覆盖 AI 429、5xx、超时、非法 JSON 和备用 Provider 切换。
- 检查消息无丢失、无重复 AI 调用、无重复撤回。
- 检查 SQLite inbox/outbox 重试、审计、任务和计划重启恢复。
- 每次异常保留完整排障包，不只保存截图。

## 9. 安全与恢复要求

- 报告中不写 API Key、Cookie、Token、Authorization 或账号密码。
- 真实群写操作必须先保存原状态。
- 禁言测试后立即解禁。
- 改名测试后恢复原名。
- 公告测试后恢复原公告与置顶状态。
- 全群禁言测试后恢复允许发言。
- 不在真实群执行移出成员。
- 回执不确定时停止自动重试，转人工确认。
