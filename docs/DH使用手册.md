# DH BOT 3.0 大白话使用手册

DH BOT 是 Windows 上的旺商聊群管理工作台。它把群消息、成员、规则、知识库、AI、任务、摘要和审计放在一个桌面程序里管理。

正式版只连接本机真实旺商聊的 `127.0.0.1:9222`。开发测试工具、测试端口和测试数据不会包含在正式安装包或便携包中。

## 1. 直接开始

1. 安装旺商聊。
2. 双击 `DH-BOT.exe`。
3. 默认会自动查找并启动旺商聊。发现多个安装位置时，进入“设置”选择正确的 EXE 路径并保存；也可随时点“启动 / 显示旺商聊”。
4. DH BOT 会用 9222 DevTools 启动旺商聊，并把登录窗口带到前台。首次使用请在旺商聊完成登录，等待会话初始化。
5. 回到 DH BOT，右上角显示“已连接”后，进入“群组与成员”同步群。

不需要安装 Go、Rust、.NET、Java、VC++ 或 SQLite。安装版包含 WebView2；便携版优先使用系统已有的 WebView2，缺少时会显示中文提示。

旺商聊已经运行但没有开启 9222 时，DH BOT 会先询问是否重启。确认后只会结束已选择路径对应的旺商聊进程，再以 DevTools 参数重新启动；点取消则不会结束任何进程。

## 2. 登录状态与本机数据

- DH BOT 不保存旺商聊账号和密码。Cookie、Token、Local Storage 仍由旺商聊自己的目录保存。
- “固定登录分区”用于让旺商聊复用 `dh-primary` 登录分区。第一次应用或旺商聊升级后，可能弹出一次 Windows UAC；程序会先备份脚本，失败会回滚。
- 数据库位于 `%APPDATA%\DH\3.0\dh.db`；密钥位于同目录的 `secrets.dat`，Windows 使用当前用户的 DPAPI 加密。
- 日志位于 `%APPDATA%\DH\3.0\logs`，会过滤 API Key、Cookie、Token 和 Authorization 内容。
- 3.0 使用新数据库，不迁移旧 Go 版本的测试数据。旧文件会归档到 `%APPDATA%\DH\legacy-backups`。

## 3. 先理解三个开关

1. **群启用与规则**：只有启用的群才进入相应的自动流程。确定性规则独立运行。
2. **AI 自动化**：在群成员页点“AI 自动化”展开。可分别控制 AI 总开关、回复、任务、撤回、禁言和移出。撤回、禁言、移出默认关闭。
3. **人工接管**：暂停当前群的 AI 回复和 AI 动作，固定规则不会因此关闭。

当前账号不是群主或管理员时，群管理写操作会被拒绝。调试页中能力显示“待校准”时，DH BOT 仍可读取数据，但不会自动执行对应写操作；“已校准”表示当前旺商聊版本和脚本版本已经通过契约校准。

## 4. AI 什么时候回复

群内只有明确提及 `@DH` 才会触发 AI。例如：

```text
@DH 这个流程怎么走？
@ DH 帮我查一下任务
```

普通聊天、只写 `DH`、普通问句都不会触发。AI 会优先使用当前群已绑定的知识库与最近上下文；没有资料时会说明资料不足，不会把其他群资料带进来。

AI 可以自然聊天，但重点保持在群规、FAQ、流程、任务和管理员配置。涉及资金、账号、验证码、身份资料或争议事项时，应由管理员人工确认。

在“设置”中填写 Base URL、模型和 API Key 后，点“测试 AI”可离群测试。测试窗口不读取群消息、不发送消息，也不会执行撤回、禁言、移出或创建真实任务。模型默认是 `deepseek-v4-pro`，服务地址和密钥默认留空。

## 5. 各页面怎么用

### 总览

查看旺商聊连接、本地数据库、已启用的 AI 群和最近审计。每日摘要只在此页显示，默认不发到群里。

“立即检查”用于重新检查 DevTools、NIM 和当前账号状态。

### 群组与成员

先在“群组”选择目标群，再切换到“成员”。群和成员用稳定 ID 识别：群使用 `groupId`，成员优先使用 `userId`，必要时用 `nimId` 合并身份；显示名称变化不会变成另一个成员。

- 搜索群名，选择后再管理成员。
- 群组页顶部显示“共 N 个群”。点“批量公告”“批量全员禁言”或“批量解除全禁”后进入多选模式；“全选当前搜索结果”只选择当前能看到的群。
- 批量公告使用同一份内容。窗口会列出所选群，AI 优化只修改草稿；发布后逐群显示成功、失败或“请到旺商聊确认”。明确失败的群可单独重试。
- 批量全员禁言和解除全禁同样按群顺序执行。当前旺商聊版本的能力状态为“待校准”时按钮保持停用，并在鼠标停留时说明原因。
- 成员页支持搜索名称或旺商号、角色筛选、分页、单选和批量选择。
- 手工操作包括改群名片、禁言、解禁、移出、全员禁言、解除全禁、清理封禁成员和恢复名称。它们都需要管理员权限，执行结果会写进审计。
- 成员标题显示群人数、已识别数和缺口。成员名单不完整时，DH BOT 保留已知成员，并持续通过后续同步、成员事件和发言补齐，不会直接把缺少的成员当作离群。

#### 群名片自动化

“群名片自动化”与 AI 无关。先点“生成建议”，核对预览后再点“一键执行”。

- 正常名称会生成简短建议；冲突、空名、`1`、`.` 或纯数字会使用固定编号。
- 前缀可以修改，固定后缀只读。已有编号成员改前缀时，程序会询问是否一并更新。
- 打开“自动改名”后，新成员进入队列；改名成功并回读验证后才更新锁定名称和欢迎流程。
- 群主、管理员、当前登录账号与系统账号不进入自动改名。

欢迎语中的 `[成员]` 会替换为群名片，因此欢迎显示的是 `@「名称」`，不是内部 ID。

### 消息台

按群名称选择一个或多个群后，可发送人工文本。列表支持按群、关键词和消息类型查看；类型显示为“文本”“图片”“名片”“其他”。

消息会先写入本机 SQLite，再确认旺商聊队列，之后按群串行处理。重复消息不会重复执行规则、AI 或外部动作。

### 规则

规则页用于确定性群管理。规则可设为全局规则，也可只作用于一个群；支持包含、精确、前缀、正则和 AI 语义匹配。

- 新建规则后先选择匹配方式、内容、优先级、时间窗口和冷却时间。
- 规则默认是观察模式。打开“自动执行”并启用后才会做实际动作。
- 动作可勾选撤回、禁言、移出、拉黑和提示。建议先只使用撤回，确认效果后再单独开启高影响动作。
- 规则支持 JSON 导入与导出。`DH-BOT-Default-Rules.json` 是 DH BOT 默认模板；导入后仍需管理员明确启用。

### 知识与 AI

知识库可以一个库绑定多个群，一个群使用多个库。

1. 点“新建知识库”，填写名称和说明。
2. 保存或导入 UTF-8 的 TXT、Markdown 文档。
3. 在“使用群”勾选需要使用该资料的群，再点“保存绑定”。

没有绑定群的知识库不会进入任何 AI 请求。内置只读库需要先“复制为可编辑”才能修改。文档会在本机进行关键词和中文字符 n-gram 检索。

### 任务与计划

页面分为“任务”“开关群计划”“每日摘要”。

- **任务**：保存待办、所属群、负责人旺商号、截止时间、提醒时间与状态。提醒默认不替代人工判断，只有相关群权限与设置允许时才会发送。
- **开关群计划**：按电脑当前时区设置每日开群和关群时间。开群允许全员发言，关群执行全员禁言。一个群不能同时属于两条启用计划；支持跨午夜，重启后会按当前时段校正。
- **每日摘要**：选择群与生成时间后保存。摘要只显示在总览，不会自动发送到群里；也可以手动生成当天摘要。

### 审计

审计记录连接、成员同步、规则命中、AI、任务、计划及手工群管理操作。可按群、级别、日期和关键词筛选，点一行查看详情，支持导出 CSV 或 JSON。

协议回执、业务错误和请求 ID 会被归档；敏感字段在写入审计前脱敏。

### 设置

设置页有两部分：旺商聊连接和 AI 提供商。

- 旺商聊路径可自动发现，也可粘贴或从候选列表选择。“自动启动或显示旺商聊”默认开启；点“保存启动设置”后供下次启动使用。
- 点“启动 / 显示旺商聊”会立即启动或把已有窗口恢复到前台。
- 连接地址在正式版固定为 `http://127.0.0.1:9222`，不能切换到测试端口。
- AI 支持 OpenAI-compatible Base URL 或 Webhook；API Key 输入框为遮罩，留空保存不会覆盖已经保存的密钥。
- 这里也可查看数据库路径、schema、当前页面、NIM 账号，并重置关闭行为选择。

### 调试

连接异常先进入“调试”并点“立即检查”。页面展示 DevTools、NIM、当前协议页面、能力校准、本地数据库和固定登录分区维护状态。

- `DevTools 已打开`：9222 可以访问，但会话可能还在登录或初始化。
- `等待登录` / `nim-not-ready`：点设置页的“启动 / 显示旺商聊”，在旺商聊完成登录后稍等，再点“立即检查”。
- `端口被占用`：9222 不是旺商聊时，DH BOT 不会结束其他程序。
- 固定登录分区维护失败或旺商聊升级后，可在此应用补丁或恢复原文件。恢复只还原启动脚本，不删除旺商聊账号数据。

群公告按当前旺商聊文件版本和主脚本哈希显示能力状态。2.7.7 已通过公告读取、创建、更新和广播消息的脱敏协议校准；其他版本先显示“待校准”。全员禁言和解除全禁仍需双群真实回执校准，校准前入口保持停用。

## 6. 托盘与退出

- 最小化会进入 Windows 右下角通知区，程序继续处理已启用的工作。
- 点击关闭时会根据已选择的行为询问“挂到托盘”或“退出 DH BOT”；可在设置页重置该选择。
- 双击托盘图标可恢复窗口；右键菜单可显示窗口、暂停或恢复全部自动化、真正退出。
- Windows Explorer 重启后，DH BOT 会重新注册托盘图标。

## 7. 常见问题

### 一直等旺商聊

在“设置”点“启动 / 显示旺商聊”。确认旺商聊窗口已经登录，再到“调试”点“立即检查”。浏览器访问 `http://127.0.0.1:9222/json/list` 时应能看到旺商聊页面。

### 已连接但没有群

确认当前旺商聊账号已经加入群，然后到“群组与成员”刷新或同步群。首次连接不会自动启用任何群。

### AI 没有回复

确认当前群 AI 总开关和“自动回复”已经打开，消息中必须明确写 `@DH`，并检查设置页已经保存可用的 AI 配置。人工接管开启时，AI 回复会暂停。

### 规则或成员操作失败

确认账号是当前群管理员，并在“调试”确认相应能力为“已校准”。具体权限或业务错误请在“审计”中查看详情。

### 同步成员数比群资料少

旺商聊返回的成员名单可能是部分数据。DH BOT 会显示覆盖缺口并继续补齐；未出现在可用来源中的成员不会被错误删除。

## 8. 推荐上线顺序

1. 连接旺商聊，只读检查群和成员。
2. 只启用一个测试群。
3. 配置知识库与 AI，先只开启 AI 回复。
4. 导入或新建规则，先使用观察模式或仅撤回。
5. 在审计中确认消息、权限和回执，再逐项开启自动改名、任务提醒、禁言或移出。
6. 最后再启用其他群和每日计划。

生产版仅提供真实旺商聊功能，不显示内部调试模块、测试群或测试数据入口。
