# Rust Web 登录

`dh-server serve-rust` 运行独立 Rust 认证服务。浏览器提供账号输入和人工验证，业务登录、请求签名、续期以及 NIM 认证和心跳由 Rust 执行。运行时无需官方客户端、Node 或 DevTools；验证组件仍需浏览器网络访问。

## 启动

```sh
cargo build --manifest-path crates/dh-server/Cargo.toml --locked --release
cd tauri3
pnpm build:web
cd ..
crates/dh-server/target/release/dh-server init-admin ./DH-web-data
DH_PROTOCOL_CONFIG=/secure/dh-deployment.json \
  crates/dh-server/target/release/dh-server serve-rust ./DH-web-data ./tauri3/dist-web
```

默认只监听本机 8787 端口。反向代理部署时，在最后增加准确的 HTTPS Origin。管理员密码与旺商聊密码相互独立；先进入管理页面，再提交旺商聊账号和页面中的人工验证。

## 部署配置

配置是最大 64 KiB 的 JSON 对象，拒绝未知字段。包含以下字段；不要提交真实配置到仓库。

| 字段 | 内容 |
| --- | --- |
| origin | 经核对的业务 HTTPS 来源 |
| headers | 经核对的版本和设备请求头；旧账号认证头被移除 |
| metadata | 14 项请求元数据；账号和账号 MAC 字段在登录前重置 |
| signing_seed | Base64 编码的 32 字节设备签名种子 |
| body_key | Base64 编码的 32 字节业务封装密钥 |
| server_key | Base64 编码的 32 字节服务端交换公钥 |
| captcha_id | 对应应用的人工验证组件标识 |
| app_key | 经核对的 NIM 应用标识 |
| device_id | 稳定的设备标识 |

首次启动通过 `DH_PROTOCOL_CONFIG` 导入经核对的配置，输入文件权限必须为 0600，最大 64 KiB，不允许符号链接。验证成功后配置保存为数据目录中的 `deployment.sealed`。以后直接执行 `dh-server serve-rust DATA_DIR UI_DIR`，不需要该环境变量、官方客户端或调试工具。配置仍需要由部署方提供，当前没有内置第三方服务密钥或自动分发界面。

`protocol.key` 是本机主密钥，`deployment.sealed` 和 `session.sealed` 使用随机密封盒加密；目录权限 0700，文件权限 0600，原子替换写入。备份时必须将密钥与密文作为同一套凭据保护；主密钥与密文在同一主机，不能防御已经控制服务用户的攻击者。不要将这些文件放进代码仓库或诊断包。源 JSON 导入后可从部署目录移走。

Linux 安装使用 `package/web/dh-server.service`，服务账号为 `dhbot`，程序和静态页面分别放在 `/opt/dh-bot/dh-server`、`/opt/dh-bot/web`，数据目录为 `/var/lib/dh-bot-web`。先以该账号完成 `init-admin` 和首次配置导入，再启用 systemd 服务。模板采用两个 Tokio 工作线程、单 Rust 进程、SQLite 和静态 Web，无 Node/Electron 运行依赖。通过 Nginx 对外提供 HTTPS 时，为 ExecStart 添加实际 HTTPS Origin 参数。

## 会话行为

- 同一服务实例维护一个旺商聊会话，操作需要有效管理员会话和匹配的 Origin。
- 管理端可同时保持最多 32 个浏览器会话，退出只注销当前浏览器；旺商聊账号仍由整个实例共享，不能将不同浏览器当作独立账号实例。
- 每分钟最多五次登录提交；并发登录或续期返回忙状态。
- 新登录先移除旧会话；只有绑定校验和业务读取成功后才显示账号已登录。
- NIM 认证后发送心跳，后台每 15 秒检查，响应超时 5 秒；发现断线立即续期重连，失败后以 1/2/4/8/16/30 秒间隔重试。
- 暂时的续期网络失败保留现有业务会话，明确过期响应会清理会话。
- 默认不保存密码；勾选“记住账号密码”后，提交的账号密码加密保存到 `login.sealed`，页面只显示已保存账号，不取回密码明文。可删除保存记录，取消勾选后再次提交也会清除。保存记录不代表登录验证通过，使用它登录仍需人工验证；退出账号保留此可选记录，删除按钮独立清除。验证码和验证挑战不保存。成功登录后另外加密保存业务会话，重启后续期 NIM；退出、新账号登录和明确过期会清除业务会话。管理员 Web 会话仍只在内存保存。
- 密码登录返回设备变更码 1069 时，Rust 请求设备验证短信，Web 切换到六位验证码表单。验证码提交和短信重发均使用新的人工验证结果；重发至少间隔 60 秒，验证上下文最多保留 10 分钟。
- 浏览器只收到随机验证标识和脱敏手机号，短信 key 与完整手机号留在服务端内存。返回账号登录、新登录或退出会清除验证上下文，旧标识不能继续使用。此流程按官方客户端分支接入，实际短信账号仍需现场验收。

## Web 业务接口

Web 分发层复用 82 个桌面业务命令，覆盖群配置、成员管理、规则、知识库、活动、计划、任务、AI 设置、摘要、消息查询和审计；参数类型、账号一致性、管理权限及回执归档使用相同处理函数。分发文件由 `tools/web-dispatch-generator` 从 Rust 语法树生成，使用 `--check` 检查命令漂移。

诊断、运行任务状态、失败确认和协议能力由 Web 宿主提供；诊断包通过需要管理员会话的临时下载地址返回，不开放任意文件路径下载。后台业务工作循环与 WebSocket 页面事件已接入。Web 构建不显示桌面启动、托盘或协议校准入口。

Rust 网关已接入业务群列表、带游标的成员读取，以及禁言、解禁、名片修改、移除、全群发言和已有公告的读取/修改/删除。成员数据仅有 HTTP 来源时保持部分名单状态，不能据此判定缺席成员已退群。写操作进行权限校验与尽可能的状态回读，结果无法确认时返回未知，不重复提交。

**最新状态：**独立 NIM 消息编解码、收发/ACK、AI 回复、公告和撤回已完成真实双账号验证。成员禁言/解禁使用业务 HTTP 与 NIM 并回读禁言名单，已验证实际限制发送。尚未验收全部群管动作、定时任务、离线撤回补偿与长期运行，详见 [最终阶段验收](acceptance/2026-09-17/RESULTS.md)。原 `serve-cdp` 保留官方客户端依赖，不能代表 Rust 模式。

共享命令测试覆盖知识库 CRUD 和账号不匹配拒绝，服务测试覆盖鉴权、Origin、参数错误和诊断下载过期。真实成员映射和会话重启已有阶段验证；测试夹具不能替代目标部署验收。

## 管理员首次激活与公网部署

管理员认证改为账号与密码。运行 `dh-server init-admin DATA_DIR` 获取仅显示一次、30 分钟有效的激活码，再启动服务并在 Web 完成首次激活；重复执行会使旧码失效。未激活时不运行后台业务任务，不开放业务接口。即使尚未导入旺商聊部署配置也能完成管理员激活。

已有 `admin-password.hash` 的实例显示迁移页面，需要验证原密码并设置新管理员账号及密码。迁移前旧凭据不能访问业务。账号为 3–32 位 ASCII 字母、数字、下划线或短横线（忽略大小写）；密码为 15–128 字符，不去除空格。管理员密码使用 Argon2id（19 MiB、2 次迭代、并行度 1）加盐哈希，保存在权限 0600 的 `admin.db`，不与旺商聊保存密码混用。

顶部管理栏的“管理员账号设置”支持验证当前密码后改密。遗忘密码时在服务器执行 `dh-server reset-admin DATA_DIR` 获取一次性重置码，在登录页选择重置。改密或重置后全部管理会话撤销。Cookie 有效期最多 8 小时，30 分钟没有页面点击或键盘操作即失效；后台轮询不延长会话。

认证接口每来源 IP 每分钟 5 次、每实例每接口每分钟 30 次；账号连续失败触发递增暂缓，持久化到数据库；同时最多执行两个密码哈希。认证体上限 16 KiB。只有 `DH_TRUSTED_PROXIES` 中列出的直接连接 IP 可提供单值 `X-Real-IP`，默认忽略该头。Nginx 必须覆盖该头为 `$remote_addr`，不可透传客户端伪造值。公网使用 HTTPS 和准确的 PUBLIC_ORIGIN，Rust 继续仅监听回环地址。参见 `package/web/nginx.conf.example`，限流 zone/map 放在 http 块，location 放在 HTTPS server 块。

管理员密钥、数据库和密封凭据不能上传仓库或诊断包。当前 CSP 为报告模式，尚未强制限制验证码外部资源；真实 Linux HTTPS 部署及验证码供应商域名白名单仍需目标环境验证。
