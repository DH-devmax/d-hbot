最快上手
1. 启动旺商聊并登录。
2. 旺商聊启动参数加入 --remote-debugging-port=9222。
3. 双击 DH-BOT.exe。
4. 进入“群组与成员”，选中目标群后点“同步群”。
5. 确认当前账号在目标群是群主或管理员，选中群后点“启用 / 停用”。
6. 先在测试群验证规则，再逐个启用正式群。
7. 先点“预览”，核对建议名称，再点“一键执行”。

一键启动旺商聊和 DH
  set "WSL_EXE=C:\Path\To\WangShangLiao.exe"
  Start-DH.vbs

识别规则
  群看 groupId。群名变化后仍是同一群。
  成员优先看 userId，详情缺失时看 nimId。群名片变化后仍是同一成员。
  欢迎和改名提示使用群名片，例如 @「张三」，不使用数字 ID。
  DH 不把某个群 ID 写死在程序里，群由运行时列表选择。

界面
  “群组与成员”使用“群组 / 成员”左右 TAB；先在群组 TAB 选群，再切到成员 TAB，DH 会自动生成该群建议名称。
  每日摘要使用本机时区时间选择器，结果只显示在总览仪表盘，不发送到群里。
  规则首次使用自动填充全局 ZCG-Compatible-Rules.json；内置模板只撤回，新增关键词规则默认也只勾选撤回。
  规则表的“状态”列明确显示已启用或已停用。
  窗口最小为 1180x760；最小化或关闭后驻留 Windows 通知区，托盘右键可暂停自动化或退出。
  消息、规则、知识、任务和审计按群名称下拉多选，不需要手填群 ID。
  成员标题显示群人数、已识别数、覆盖缺口、待备注和失败数。
  有效名称压缩成两字简称；缺少名称时从 DH群员0001 开始分配固定编号。
  群名片前缀移到设置页；修改时，“确认”同步更新已有编号成员，“保留”只影响新成员。
  禁言时长按分钟填写，支持 1 到 43200 分钟。
  “AI 自动回复”只在群成员明确 @DH 时回复。
  总览暂停自动化时，管理员明确点出的“一键执行”仍会运行；成员 TAB 的“暂停”会暂停该群名片队列。
  成员表支持数字序号和复选框多选；恢复按钮按勾选数量切换单项/批量文案。
  “清理封禁成员”根据旺商聊 accountState 识别注销和封禁账号，确认后只移出普通成员。
  注销或封禁账号不进入一键改名和自动改名，请使用“清理封禁成员”处理。
  “每日群发言计划”按本机时区开群和关群，一个计划可绑定多个群，跨午夜也可使用。

默认群管
  只保存一套 groupId=0 的全局规则，所有已启用群共用。
  加权字符、行数、图片次数、改名、黑名单和 AI 语义模板命中后默认只撤回。
  内置模板不执行禁言、移出或拉黑。
  群主和管理员默认豁免。
  AI 广告、辱骂、诈骗规则默认只观察。

AI
  默认 Base URL：留空（请填写你的 OpenAI-compatible 地址）
  默认模型：deepseek-v4-pro
  OpenAI-compatible：填写 Base URL、模型和 API Key。根地址会自动补充 /v1。
  Webhook：AI 类型填 webhook，再填写 Webhook URL。
  只有明确 @DH 会触发群聊回复；普通问句和单独出现 DH 不会触发。
  普通消息可做语义分类，但不会因此自动回复。
  @DH 预测 彩种名称：本地先算近期窗口、冷热、遗漏和候选方向，群里不显示上游接口与原始字段。

数据

运行依赖
  正常使用只运行 DH-BOT.exe，不用安装 Go、.NET、Java、VC++ 运行库或 SQLite。
  旺商聊需要已经安装、登录，并开启 9222 DevTools 端口。

更多说明见 DH-Manual-ZH.md。
